# Khmer Food & Tourism — អាហារ និងទេសចរណ៍ខ្មែរ
**Mobile Application for Android and iOS**

កម្មវិធីទូរស័ព្ទដៃ **“Khmer Food & Tourism” (អាហារ និងទេសចរណ៍ខ្មែរ)** ត្រូវបានបង្កើតឡើងយ៉ាងពេញលេញ (Fully Functional Application) ដោយប្រើប្រាស់ភាសាខ្មែរជាភាសាចម្បង រួមជាមួយភាសាអង់គ្លេស សម្រាប់ការផ្សព្វផ្សាយមុខម្ហូបខ្មែរប្រពៃណី បញ្ជីភោជនីយដ្ឋាន និងតំបន់ទេសចរណ៍ស្រស់ត្រកាលទូទាំងប្រទេសកម្ពុជា។

---

## 🌟 លក្ខណៈពិសេសចម្បង (Key Features)

### 1. វិចិត្រសាលមុខម្ហូបខ្មែរ (Khmer Food Gallery)
- រូបភាពគុណភាពខ្ពស់នៃមុខម្ហូបបុរាណ និងទំនើប (អាម៉ុកត្រី, សម្លកកូរ, ឡុកឡាក់សាច់គោ, គុយទាវភ្នំពេញ, នំបញ្ចុកសម្លខ្មែរ, នំផ្លែអាយ...)
- ឈ្មោះជាភាសាខ្មែរ និងអង់គ្លេស ការពិពណ៌នាលម្អិត កម្រិតកាឡូរី រយៈពេលចម្អិន កម្រិតលំបាក
- តម្លៃប៉ាន់ស្មានជាប្រាក់រៀល (៛) និងប្រាក់ដុល្លារ ($)
- តារាងគ្រឿងផ្សំដែលអាចចុច Checkbox បាននៅពេលទិញគ្រឿងផ្សំ ឬកំពុងចម្អិន
- វិធីចម្អិនតាមលំដាប់ (Step-by-step cooking instructions with tips)
- ប្រព័ន្ធអានសម្លេងជាភាសាខ្មែរ (Text-to-Speech audio reader)

### 2. បញ្ជីហាងអាហារ និងភោជនីយដ្ឋាន (Khmer Restaurant Directory)
- បណ្តុំហាងអាហារល្បីៗនៅភ្នំពេញ សៀមរាប កំពត កែប បាត់ដំបង...
- បង្ហាញអាសយដ្ឋាន លេខទូរស័ព្ទ (ចុចទូរស័ព្ទទៅកាន់ហាងភ្លាមៗ) ម៉ោងបើកដំណើរការ កម្រិតតម្លៃ ($ ដល់ $$$$)
- តភ្ជាប់ Google Maps ផ្ទាល់សម្រាប់នាំផ្លូវ (GPS Directions)
- មុខងារសម្រាប់ **ម្ចាស់ហាងអាហារអាចចុះបញ្ជីហាងរបស់ខ្លួនបានដោយខ្លួនឯង** (Self Restaurant Registration)

### 3. តំបន់ទេសចរណ៍ស្រស់ត្រកាល (Beautiful Tourist Destinations)
- ប្រាសាទបុរាណ (អង្គរវត្ត, បាយ័ន, ព្រះវិហារ...), ធម្មជាតិ & ទឹកធ្លាក់ (ទឹកធ្លាក់ប៊ូស្រា), ភ្នំ (ភ្នំបូកគោ), កោះ និងឆ្នេរសមុទ្រ (កោះរ៉ុងសន្លឹម)
- បង្ហាញព័ត៌មានថ្លៃសំបុត្រចូលទស្សនា (ភ្ញៀវជាតិ/អន្តរជាតិ)
- រដូវកាលល្អបំផុតសម្រាប់ដំណើរកម្សាន្ត (Best time to visit)
- ចំណុចលេចធ្លោមិនគួររំលង (Key Highlights) និងប៊ូតុងតភ្ជាប់ Google Maps

### 4. សហគមន៍ និងការចែករំលែក (Sharing & Community Feed)
- ផ្ទាំង Feed សម្រាប់អ្នកប្រើប្រាស់ និងម្ចាស់ហាងចែករំលែករូបភាព មុខម្ហូប រូបមន្ត និងកន្លែងដើរលេង
- ប៊ូតុង Like (Animated Heart) និងប្រព័ន្ធ Comment បញ្ចេញមតិយោបល់ផ្ទាល់
- ចែករំលែកបន្តទៅកាន់ **Telegram**, **Facebook** ឬចម្លងតំណភ្ជាប់ (Copy Link)

### 5. ការស្វែងរក និងទីតាំង (Search & Location Filters)
- របារស្វែងរកសកល (Universal Real-time Search) លើមុខម្ហូប ហាង និងតំបន់ទេសចរណ៍
- តម្រងតាមខេត្ត/ក្រុង (ភ្នំពេញ, សៀមរាប, កំពត, បាត់ដំបង, មណ្ឌលគិរី, ព្រះសីហនុ...)
- តម្រងតាមប្រភេទមុខម្ហូប (សម្ល, ឆា, អាហារពេលព្រឹក, បង្អែម)

### 6. ផ្ទាំងគ្រប់គ្រងរដ្ឋបាល (Admin Dashboard)
- ស្ថិតិទូទៅ (Total Foods, Restaurants, Destinations, Community Posts, Users)
- គ្រប់គ្រងមុខម្ហូប (Add / Delete Food)
- គ្រប់គ្រងហាងអាហារ និង**ពិនិត្យអនុម័តហាងអាហារថ្មី (Approve Pending Restaurants)**
- គ្រប់គ្រងតំបន់ទេសចរណ៍ (Add / Delete Tourist Spots)
- ត្រួតពិនិត្យ និងលុបការបង្ហោះមិនសមរម្យក្នុងសហគមន៍ (Moderation)
- គ្រប់គ្រងសិទ្ធិអ្នកប្រើប្រាស់ (Admin / Shop Owner / Regular User)

### 7. ការរចនាតាមស្តង់ដារទូរស័ព្ទដៃ (Mobile UI/UX Design)
- កំណត់ទម្រង់ទូរស័ព្ទដៃជាមួយ Safe Area, Bottom Navigation Bar, Modal Drawers
- ជម្រើសប្តូរមើលតាមទម្រង់ទូរស័ព្ទ (Mobile Phone Bezel) ឬពេញអេក្រង់ (Full Responsive)
- គាំទ្រពុម្ពអក្សរខ្មែរស្អាតៗពី Google Fonts (`Kantumruy Pro`, `Moul`, `Battambang`)
- ពណ៌តំណាងវប្បធម៌ខ្មែរ (Angkor Gold, Royal Warm Amber, Temple Slate)

## 📦 របៀប Build Android APK (Native APK Generation)

គម្រោងនេះត្រូវបានបំពាក់ដោយ **Capacitor Android Native Project** រួចជាស្រេច នៅក្នុងថត `android/`។

### ជំហានទី ១៖ Compile Web Assets
```powershell
npm.cmd run build
npx.cmd cap sync android
```
*(ឬគ្រាន់តែចុចពីរដងលើឯកសារ `Sync_And_Build_Android.bat`)*

### ជំហានទី ២៖ បង្កើត APK តាម Android Studio
1. បើកកម្មវិធី **Android Studio**។
2. ជ្រើសរើស **Open an Existing Project** រួចជ្រើសរើសថត៖
   ```text
   f:\Soft\System Program 2027 kimseng\KhmerFoodTourism\android
   ```
3. រង់ចាំ Gradle Sync រួចរាល់។
4. ចុចលើ Menu **Build** -> **Build Bundle(s) / APK(s)** -> **Build APK(s)**។
5. ឯកសារ APK នឹងស្ថិតនៅត្រង់៖
   ```text
   android/app/build/outputs/apk/debug/app-debug.apk
   ```

### ជំហានទី ៣៖ បង្កើត APK តាម Command Line (បើមាន JDK / Android SDK)
```powershell
cd android
.\gradlew.bat assembleDebug
```
